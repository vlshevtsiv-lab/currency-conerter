# Конвертер Валют (UAH -> EUR/USD)

Цей проєкт реалізує простий конвертер валют, що дозволяє конвертувати гривні (UAH) у євро (EUR) або долари США (USD) за поточними курсами.

## Опис

Програма приймає суму в гривнях (UAH) від користувача, запитує валюту для конвертації (EUR або USD), після чого виводить еквівалентну суму в обраній валюті. Курс валют для конвертації заданий статично в програмі.

## Ключові моменти

- **Валюти підтримуються**: EUR (Євро), USD (Долар США).
- **Курси валют**:
  - 1 UAH = 0.025 EUR
  - 1 UAH = 0.027 USD
- Програма обробляє помилки, пов'язані з некоректним введенням даних (наприклад, введення від'ємних чисел або невірних валют).

## Інструкція з використання

1. Запустіть програму.
2. Введіть суму в гривнях (UAH).
3. Виберіть валюту для конвертації, ввівши `EUR` або `USD`.
4. Програма виведе результат конвертації на екран.
